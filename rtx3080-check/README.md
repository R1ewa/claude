# Проверка б/у RTX 3080 на компьютере продавца

Набор для флешки: автоматическая проверка видеокарты «от и до» за ~15 минут.

## Что положить на флешку (подготовьте ДОМА, у продавца может не быть интернета)

Создайте на флешке папку, например `GPU-CHECK`, и положите в неё:

| Файл | Откуда взять | Зачем |
|---|---|---|
| `Test-RTX3080.ps1` | из этой папки | основной скрипт проверки |
| `CHECK_GPU.bat` | из этой папки | запуск двойным кликом |
| **FurMark** (распакованный portable) | [geeks3d.com/furmark](https://geeks3d.com/furmark/) — подойдёт и FurMark 1, и FurMark 2 | стресс-тест: нагрев, троттлинг, стабильность |
| **memtest_vulkan.exe** | [github.com/GpuZelenograd/memtest_vulkan](https://github.com/GpuZelenograd/memtest_vulkan/releases) | тест видеопамяти (частая болячка после майнинга) |
| **GPU-Z** | [techpowerup.com/gpuz](https://www.techpowerup.com/gpuz/) | ручная проверка: Hot Spot, Memory Junction, детектор подделок |

FurMark и memtest_vulkan можно класть в подпапки — скрипт найдёт их сам.
Свежий драйвер NVIDIA тоже стоит закинуть на флешку на случай, если на ПК продавца его нет.

## Как запускать

1. Вставьте флешку, откройте папку.
2. Двойной клик по **`CHECK_GPU.bat`**.
   - Если Windows SmartScreen ругается: «Подробнее» → «Выполнить в любом случае».
3. Во время стресс-теста **смотрите на экран**: цветные точки, полосы, мерцание, «снег» = дефект чипа или памяти.
4. В конце скрипт выведет вердикт: `OK` / `WARN` / `FAIL` по каждому пункту.
5. Полный отчёт и логи сохраняются в папку `logs_<дата>` на флешке — можно спокойно перечитать дома.

По умолчанию: стресс-тест 5 минут, тест памяти 4 минуты. Если есть время, увеличьте:

```
powershell -ExecutionPolicy Bypass -File .\Test-RTX3080.ps1 -StressMinutes 15 -VramMinutes 10
```

## Что проверяет скрипт

1. **Драйвер и определение карты** — видит ли система GPU вообще.
2. **Подлинность** — сверяет PCI Device ID чипа со списком настоящих RTX 3080
   (2206 / 2216 LHR / 220A 12GB). Название карты подделывается перешивкой BIOS
   за минуту, Device ID чипа — нет.
3. **Объём видеопамяти** — соответствует ли ревизии (10 или 12 ГБ).
4. **Шина PCIe** — x16 или нет (x1 — типичный след райзера с майнинг-фермы).
5. **Простой** — температура и потребление без нагрузки.
6. **Журнал Windows** — сбросы видеодрайвера (nvlddmkm, TDR 4101) за 14 дней.
7. **Стресс-тест** — запускает FurMark и каждые 2 секунды пишет температуру,
   частоты, мощность, обороты вентиляторов; ловит термотроттлинг, аварийные
   сбросы частот, вылеты и сбросы драйвера прямо во время теста.
8. **Тест видеопамяти** — memtest_vulkan, ищет битые ячейки VRAM.

## Что скрипт проверить НЕ может — смотрите глазами

- **GPU-Z → Sensors во время нагрузки:**
  - *Hot Spot* — если больше температуры GPU на 25–30°C и выше, прижим/паста убиты;
  - *Memory Junction* — выше 100°C под нагрузкой = высохшие термопрокладки, классика после майнинга.
- **Внешний осмотр:** сорванные шлицы винтов и пломбы (карту вскрывали), потемневший/пожелтевший текстолит у зоны VRM, следы пайки и флюса, оплавленные разъёмы питания, люфт и хруст вентиляторов, окисленные контакты PCIe.
- **Звук:** сильный писк дросселей под нагрузкой.
- **Все видеовыходы** — по возможности воткните кабель в каждый.
- Если пускают — 10–15 минут игрового бенчмарка: частоты должны держаться ~1700+ МГц (в FurMark ниже — это норма, он упирается в лимит мощности).

## Как читать вердикт

- **FAIL** (любой) — не брать, либо очень большой торг: подделка, битая память, перегрев с троттлингом, сбросы драйвера.
- **WARN** — карта живая, но есть нюансы (горячая → нужно обслуживание, история сбоев и т.п.). Повод торговаться.
- Всё **OK** + чисто по ручному чек-листу — можно брать.

Отдельный красный флаг: продавец **не даёт** запустить проверку с флешки или торопит во время стресс-теста.
