# Универсальная проверка б/у видеокарты на компьютере продавца

Набор для флешки: автоматическая проверка любой видеокарты (NVIDIA / AMD / Intel)
«от и до» за ~15 минут.

## Что положить на флешку (подготовьте ДОМА, у продавца может не быть интернета)

Создайте на флешке папку, например `GPU-CHECK`, и положите в неё:

| Файл | Откуда взять | Зачем |
|---|---|---|
| `Test-GPU.ps1` | из этой папки | основной скрипт проверки |
| `CHECK_GPU.bat` | из этой папки | запуск двойным кликом |
| **FurMark** (распакованный portable) | [geeks3d.com/furmark](https://geeks3d.com/furmark/) — подойдёт и FurMark 1, и FurMark 2 | стресс-тест: нагрев, троттлинг, стабильность (любой вендор) |
| **memtest_vulkan.exe** | [github.com/GpuZelenograd/memtest_vulkan](https://github.com/GpuZelenograd/memtest_vulkan/releases) | тест видеопамяти, работает на любых картах с Vulkan (частая болячка после майнинга) |
| **GPU-Z** | [techpowerup.com/gpuz](https://www.techpowerup.com/gpuz/) | ручная проверка: Hot Spot, Memory Junction, встроенный детектор подделок |

FurMark и memtest_vulkan можно класть в подпапки — скрипт найдёт их сам.
Свежие драйверы (NVIDIA/AMD) тоже стоит закинуть на флешку на случай, если на ПК продавца их нет.

## Как запускать

1. Вставьте флешку, откройте папку.
2. Двойной клик по **`CHECK_GPU.bat`**.
   - Если Windows SmartScreen ругается: «Подробнее» → «Выполнить в любом случае».
   - Если в системе несколько GPU (например, встройка + дискретная), скрипт спросит, какую проверять.
3. Во время стресс-теста **смотрите на экран**: цветные точки, полосы, мерцание, «снег» = дефект чипа или памяти.
   - Для карт **AMD/Intel** дополнительно держите открытым **GPU-Z → Sensors**: скрипт не может читать их температуры без стороннего софта.
4. В конце скрипт выведет вердикт: `OK` / `WARN` / `FAIL` по каждому пункту (`INFO` — просто к сведению).
5. Полный отчёт и логи сохраняются в папку `logs_<дата>` на флешке — можно спокойно перечитать дома.

По умолчанию: стресс-тест 5 минут, тест памяти 4 минуты. Если есть время, увеличьте:

```
powershell -ExecutionPolicy Bypass -File .\Test-GPU.ps1 -StressMinutes 15 -VramMinutes 10
```

## Что проверяет скрипт

Для **любой** карты:

1. **Определение в системе** — видит ли Windows карту, какой драйвер.
2. **Подлинность** — сверяет PCI Device ID чипа с базой популярных карт
   (GTX 10xx/16xx, RTX 20xx/30xx/40xx, Radeon RX 400–7000). Название карты
   подделывается перешивкой BIOS за минуту, Device ID чипа — нет. Если чип
   не соответствует названию или объёму памяти — FAIL. Если ID нет в базе —
   скрипт честно скажет и отправит сверяться в GPU-Z.
3. **Объём видеопамяти** — читается из реестра (надёжно для всех вендоров;
   стандартный WMI врёт на картах больше 4 ГБ).
4. **Журнал Windows** — сбросы видеодрайвера за 14 дней (NVIDIA `nvlddmkm`,
   AMD `amdkmdag`/`atikmdag`, Intel `igfx`, TDR 4101).
5. **Стресс-тест** — запускает FurMark, следит за загрузкой и вылетами,
   после теста проверяет журнал на сбросы драйвера **во время** нагрузки.
6. **Тест видеопамяти** — memtest_vulkan ищет битые ячейки VRAM на любой
   карте. Заодно ловит подделки с «нарисованным» объёмом памяти: при выходе
   за реальный объём сыплются ошибки.

Дополнительно для **NVIDIA** (через nvidia-smi): температура и потребление в
простое и под нагрузкой, частоты, обороты вентиляторов, термический и
аппаратный троттлинг, ширина шины PCIe (x1 — типичный след райзера с
майнинг-фермы), VBIOS и серийный номер.

## Что скрипт проверить НЕ может — смотрите глазами

- **GPU-Z → Sensors во время нагрузки:**
  - *Hot Spot* — если больше температуры GPU на 25–30°C и выше, прижим/паста убиты;
  - *Memory Junction* (есть не у всех карт) — выше 100°C под нагрузкой = высохшие термопрокладки, классика после майнинга;
  - для AMD/Intel это вообще единственный способ увидеть температуры.
- **GPU-Z, главная вкладка** — встроенный детектор подделок сам пишет `[FAKE]` в названии карты.
- **Внешний осмотр:** сорванные шлицы винтов и пломбы (карту вскрывали), потемневший/пожелтевший текстолит у зоны VRM, следы пайки и флюса, оплавленные разъёмы питания, люфт и хруст вентиляторов, окисленные контакты PCIe.
- **Звук:** сильный писк дросселей под нагрузкой.
- **Все видеовыходы** — по возможности воткните кабель в каждый.
- Если пускают — 10–15 минут игрового бенчмарка: частоты должны держаться стабильно (в FurMark частоты ниже игровых — это норма, он упирается в лимит мощности).

## Как читать вердикт

- **FAIL** (любой) — не брать, либо очень большой торг: подделка, битая память, перегрев с троттлингом, сбросы драйвера.
- **WARN** — карта живая, но есть нюансы (горячая → нужно обслуживание, история сбоев и т.п.). Повод торговаться.
- **INFO** — просто к сведению, на вердикт не влияет.
- Всё **OK** + чисто по ручному чек-листу — можно брать.

Отдельный красный флаг: продавец **не даёт** запустить проверку с флешки или торопит во время стресс-теста.
